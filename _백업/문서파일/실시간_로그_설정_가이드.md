# 🎯 터미널 → 대시보드 실시간 로그 설정 가이드

## 📋 개요
터미널에서 실행하는 봇의 출력을 대시보드에서도 실시간으로 볼 수 있게 하는 방법입니다.
**기존 봇 코드는 거의 그대로, 사이드 이펙트 최소화!**

---

## 🚀 설정 방법 (3단계)

### 1단계: 현재 사용하는 봇 파일 수정

현재 메인으로 사용하는 봇 파일 (예: `Last update_parkingbot.py`) 상단에 **2줄만 추가**:

```python
# 기존 import 구문들...
from selenium import webdriver
# ... (기타 import)

# ✨ 여기에 추가! (기존 코드 바로 아래)
from logger_helper import enable_dual_logging

def main():
    # ✨ 여기에 추가! (main 함수 첫 줄)
    enable_dual_logging()
    
    # 나머지 코드는 그대로!
    print("=== iParking 통합 자동화 프로그램 시작 ===")
    # ... (기존 코드)
```

**끝!** 이제 모든 `print()` 출력이 자동으로 `logs/bot_YYYYMMDD.log` 파일에도 저장됩니다.

---

### 2단계: 봇 실행 (터미널)

```bash
python "Last update_parkingbot.py"
```

평소처럼 터미널에서 실행하면:
- ✅ 터미널에도 출력 (기존과 동일)
- ✅ `logs/bot_20260113.log` 파일에도 동시 저장

---

### 3단계: 대시보드에서 로그 확인

**방법 1: 별도 로그 뷰어 실행**

```bash
streamlit run log_viewer.py
```

**방법 2: 기존 대시보드에 통합**

`dashboard.py`에 탭 추가:

```python
tab1, tab2, tab3, tab4 = st.tabs(["📊 주차 명단", "✍️ 수동 입력", "🔗 전체", "📋 실시간 로그"])

with tab4:
    # log_viewer.py의 코드 복사
    st.header("📋 봇 실시간 로그")
    # ... (로그 뷰어 코드)
```

## 💡 장점

### ✅ 사이드 이펙트 없음
- 기존 봇 로직은 **단 한 줄도 변경 안 함**
- `print()` 그대로 사용
- 터미널 출력도 그대로

### ✅ 실시간 모니터링
- 터미널 보지 않아도 대시보드에서 확인
- 여러 사람이 동시에 진행 상황 확인 가능
- 자동 새로고침으로 항상 최신 상태

### ✅ 로그 보관
- 날짜별로 자동 저장
- 나중에 문제 발생 시 추적 가능
- 다운로드 가능

# 중요한 이벤트만 Firebase에도 저장

## ❓ FAQ

**Q: 로그 파일이 너무 커지면?**
A: 날짜별로 자동 분리되고, 오래된 파일은 수동 삭제하면 됩니다.

**Q: 여러 봇을 동시에 실행하면?**
A: 각 봇에 다른 로그 파일명을 지정하거나, 프로세스 ID를 추가하면 됩니다.

**Q: 성능 영향은?**
A: 거의 없습니다. 파일 쓰기는 매우 빠릅니다.
