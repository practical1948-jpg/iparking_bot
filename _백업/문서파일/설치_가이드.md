## 🔧 사전 준비

### 필수 프로그램

#### 1. Python 3.8 이상
- **다운로드**: https://www.python.org/downloads/
- **설치 시 주의**: 반드시 **"Add Python to PATH"** 체크박스 선택!
- **확인 방법**:
  ```bash
  python --version
  # Python 3.8.0 이상이 나오면 OK
  ```

#### 2. Google Chrome 브라우저
- **다운로드**: https://www.google.com/chrome/
- **기본 설치로 진행**
- Chrome이 있어야 자동화가 작동합니다

#### 3. 인터넷 연결
- 패키지 설치 및 프로그램 실행에 필요

## 📦 폴더 이동 및 압축 해제

### 방법 1: 폴더 전체 복사
```
iparking-bot 폴더를 통째로 USB나 클라우드로 이동
```

### 방법 2: 압축 파일 생성 (권장)
```
1. 원본 컴퓨터에서 배포_패키지_생성.bat 실행
2. 생성된 iparking-bot_배포패키지_YYYYMMDD_HHMMSS.zip 파일을 전송
3. 새 컴퓨터에서 원하는 위치에 압축 해제
   (예: C:\iparking-bot 또는 D:\작업\iparking-bot)
```

**⚠️ 주의**: 
- 한글 경로도 사용 가능합니다
- 어떤 위치에 설치해도 작동합니다 (상대 경로 사용)
- 단, 경로가 너무 길거나 특수문자가 많으면 피하세요

## ⚡ 자동 설치 (권장)

가장 쉽고 빠른 방법입니다!

### 1단계: 자동 설치 스크립트 실행

```
설치_및_실행.bat 파일을 더블클릭
```

### 2단계: 자동 진행 확인

스크립트가 자동으로:
- ✅ Python 설치 확인
- ✅ Chrome 브라우저 설치 확인
- ✅ 가상환경(venv) 생성
- ✅ 필요한 패키지 자동 설치
  - selenium (브라우저 자동화)
  - streamlit (대시보드)
  - pandas (데이터 처리)
  - firebase-admin (Firebase 연동)
  - plotly (그래프)
  - streamlit-autorefresh (자동 새로고침)
- ✅ Firebase 인증 파일 확인

### 3단계: 완료!

설치가 완료되면 메뉴가 나타납니다:
```
===================================
   iParking Bot 실행 메뉴
===================================
1. 주차권 등록 봇 실행
2. 대시보드 실행
3. 종료

선택: 
```

## 🔨 수동 설치

자동 설치가 실패하거나 직접 설치하고 싶을 때 사용하세요.

### 1단계: 명령 프롬프트 열기

```
iparking-bot 폴더로 이동
```

### 2단계: 가상환경 생성

```bash
python -m venv venv
```

### 3단계: 가상환경 활성화

```bash
venv\Scripts\activate
```
✅ 성공하면 앞에 `(venv)`가 나타납니다

### 4단계: 패키지 설치

```bash
pip install -r requirements.txt
```

### 5단계: 설치 확인

```bash
pip list
```
다음 패키지들이 보이면 성공:
- selenium
- streamlit
- pandas
- firebase-admin
- webdriver-manager
- streamlit-autorefresh
- plotly

## ▶️ 프로그램 실행

### 방법 1: 자동 실행 스크립트 사용 (권장)

```
설치_및_실행.bat 파일을 더블클릭
→ 메뉴에서 원하는 옵션 선택
```

### 방법 2: 직접 실행

#### 주차권 등록 봇 실행
```bash
# 가상환경 활성화
venv\Scripts\activate

# 봇 실행
cd iparking-bot
python bot_Simple_logic.py
```

**실행 후 선택**:
- `1`: CSV 파일에서 자동 등록 (5분마다 반복)
- `2`: 수동 입력 모드 (차량번호 직접 입력)

#### 대시보드 실행
```bash
# 가상환경 활성화
venv\Scripts\activate

# 대시보드 실행
cd iparking-bot
streamlit run dashboard.py
```

브라우저가 자동으로 열리고 주소창에 http://localhost:8501 표시됩니다.

## 🔍 Firebase 설정 (선택사항)

Firebase를 사용하지 않아도 프로그램은 작동하지만, 여러 컴퓨터에서 데이터를 공유하려면 필요합니다.

### Firebase 인증 파일 배치

```
iparking-bot/firebase-credentials.json
```

이 파일이 있어야 Firebase 기능이 활성화됩니다.

**Firebase 인증 파일이 없으면?**
- ⚠️ 프로그램은 정상 작동
- ❌ Firebase 연동 기능만 사용 불가
- ❌ 대시보드에서 실시간 공유 안 됨

## ❓ 문제 해결

### 🚨 "python을 찾을 수 없습니다" 오류

**원인**: Python이 설치되지 않았거나 환경 변수에 등록되지 않음

**해결**:
1. Python 설치 확인: https://www.python.org/downloads/
2. 설치 시 **"Add Python to PATH"** 반드시 체크
3. 이미 설치했다면 환경 변수 수동 추가:
   - Windows 검색 → "환경 변수 편집"
   - 시스템 변수 → Path 편집
   - Python 설치 경로 추가 (예: `C:\Python311\`)
4. 명령 프롬프트 재시작

---

### 🚨 "Chrome을 찾을 수 없습니다" 오류

**원인**: Chrome 브라우저가 설치되지 않음

**해결**:
1. Chrome 설치: https://www.google.com/chrome/
2. 기본 경로에 설치 (자동 감지됨)
3. 다른 경로에 설치했다면 프로그램이 자동으로 찾습니다

---

### 🚨 패키지 설치 실패

**원인**: 인터넷 연결 문제 또는 방화벽

**해결**:
1. 인터넷 연결 확인
2. 방화벽에서 Python 허용
3. 개별 설치 시도:
   ```bash
   pip install selenium
   pip install streamlit
   pip install pandas
   pip install firebase-admin
   pip install webdriver-manager
   pip install streamlit-autorefresh
   pip install plotly
   ```

---

### 🚨 "가상환경을 활성화할 수 없습니다" 오류

**원인**: PowerShell 실행 정책 제한

**해결**:
```powershell
# PowerShell을 관리자 권한으로 실행
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser

# 또는 명령 프롬프트(cmd)를 사용
venv\Scripts\activate.bat
```

---

### 🚨 ChromeDriver 관련 오류

**원인**: Chrome과 ChromeDriver 버전 불일치

**해결**:
- **자동 해결**: webdriver-manager가 자동으로 처리합니다
- Chrome을 최신 버전으로 업데이트하면 자동으로 맞는 버전 다운로드
- 별도 조치 불필요!

---

### 🚨 Firebase 연결 실패

**원인**: 인증 파일이 없거나 잘못된 위치

**해결**:
1. `iparking-bot/firebase-credentials.json` 파일 확인
2. 파일 내용이 올바른 JSON 형식인지 확인
3. Firebase 콘솔에서 새 인증 키 다운로드
4. **없어도 프로그램은 작동**하므로 나중에 설정 가능

## 💡 유용한 팁

### 1️⃣ 여러 컴퓨터에서 사용하기
- 각 컴퓨터에서 `설치_및_실행.bat` 한 번씩 실행
- Firebase 설정하면 데이터가 자동으로 동기화됨

### 2️⃣ 프로그램 업데이트
```bash
# 새 파일을 기존 파일과 교체
# 패키지 업데이트 (필요시)
venv\Scripts\activate
pip install -r requirements.txt --upgrade
```

### 3️⃣ 첫 실행 시간
- ChromeDriver 자동 다운로드로 첫 실행은 1-2분 걸릴 수 있음
- 두 번째부터는 빠르게 실행됨

### 4️⃣ 폴더 구조 유지
```
iparking-bot/
├── iparking-bot/           # 봇 프로그램 폴더
│   ├── bot_Simple_logic.py
│   ├── dashboard.py
│   ├── firebase_helper.py
│   └── firebase-credentials.json (선택)
├── 주차_DB_파일/           # CSV 파일 저장 폴더
├── venv/                   # 가상환경 (자동 생성)
├── requirements.txt
└── 설치_및_실행.bat
```
