 🚗 iParking 자동화 시스템 - 사용 가이드
═══════════════════════════════════════════════════════════

📌 간단 사용법
────────────────────────────────────────────────────────────

1. start.bat 더블클릭 (이것만 사용하세요!)

2. 옵션 선택 화면이 나옵니다:
   ┌─────────────────────────────────────────────────────┐
   │ 데이터 입력 방식을 선택하세요:                      │
   │ ──────────────────────────────────────────────────  │
   │   1. 주차 명단 ✓                                    │
   │   2. 수동 입력 (이름 + 차량번호 직접 입력)          │
   │ ──────────────────────────────────────────────────  │
   │ 번호를 입력하세요 (1 또는 2):                       │
   └─────────────────────────────────────────────────────┘

3. 1번 선택: CSV 파일에서 자동 처리
   2번 선택: 수동으로 이름/차량번호 입력

4. Chrome 브라우저가 자동으로 열리고 처리 시작!


═══════════════════════════════════════════════════════════
 🔧 문제 해결
═══════════════════════════════════════════════════════════

❌ "가상환경을 찾을 수 없습니다" 에러
   → 빠른_설치.bat 실행 후 다시 시도

❌ Chrome 브라우저가 안 열려요
   → Chrome 설치 확인
   → 기존 Chrome 창 모두 닫고 다시 시도

❌ 대시보드가 안 열려요
   → http://localhost:8501 직접 접속
   → 안 되면 "iParking Dashboard" 창 확인

❌ 옵션 선택 화면이 안 나와요
   → start.bat 사용 중인지 확인!
   → 다른 배치 파일 사용하면 안 됩니다

 💡 팁
