# 🚀 iParking-Bot 초기 세팅 가이드

## 📋 필수 사전 준비

### 1. Python 설치 (3.11 이상 권장)
- [Python 공식 사이트](https://www.python.org/downloads/)에서 다운로드
- 설치 시 **"Add Python to PATH"** 체크 필수!

### 2. Google Chrome 설치
- [Chrome 다운로드](https://www.google.com/chrome/)
- 이미 설치되어 있으면 OK

---

## 🛠️ 초기 세팅 순서

### 1단계: 프로젝트 다운로드
```bash
# GitHub에서 다운로드하거나 폴더를 복사
# 압축 풀기
```

### 2단계: 가상환경 생성
```powershell
# PowerShell에서 프로젝트 폴더로 이동
cd "경로\iparking-bot"

# 가상환경 생성
python -m venv venv
```

### 3단계: 가상환경 활성화
```powershell
# PowerShell
.\venv\Scripts\activate

# 성공하면 프롬프트 앞에 (venv) 표시됨
```

### 4단계: 패키지 설치
```powershell
# 가상환경 활성화 상태에서
pip install -r requirements.txt
```

### 5단계: 주차_DB_파일 폴더 준비
```powershell
# 프로그램 실행 시 자동으로 생성되지만, 미리 만들어도 됨
mkdir 주차_DB_파일
```

## 🎯 프로그램 실행

### 1. iParking 자동 등록 봇
```powershell
# 가상환경 활성화 상태에서
cd iparking-bot
python bot_Simple_logic.py
```

### 2. 대시보드 (Streamlit)
```powershell
# 가상환경 활성화 상태에서
cd iparking-bot
streamlit run dashboard.py
```

### 3. 주차 명단 생성
```powershell
cd "주차 명단 작업"
python 주차명단_자동화.py
```

## 🔧 트러블슈팅

### 문제 1: `venv\Scripts\activate` 권한 에러
```powershell
# PowerShell 관리자 권한으로 실행 후
Set-ExecutionPolicy RemoteSigned
```

### 문제 2: `pip install` 실패
```powershell
# pip 업그레이드
python -m pip install --upgrade pip

# 다시 시도
pip install -r requirements.txt
```

### 문제 3: Chrome 디버깅 포트 충돌
```powershell
# 기존 Chrome 프로세스 종료
taskkill /F /IM chrome.exe

# 프로그램 재실행
```
