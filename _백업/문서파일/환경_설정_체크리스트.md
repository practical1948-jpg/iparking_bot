# 환경 설정 체크리스트

이 문서는 iParking-Bot을 실행하기 위해 필요한 모든 환경 설정을 확인하는 가이드입니다.

## ✅ 자동으로 확인/설치되는 항목

`설치_및_실행.bat` 스크립트가 자동으로 확인/설치합니다:

### 1. Python 설치 확인
- ✅ Python 3.8 이상 설치 여부 확인
- ✅ 버전 출력
- ❌ 없으면 설치 안내

### 2. Chrome 브라우저 확인
- ✅ 기본 경로 확인 (`C:\Program Files\Google\Chrome\Application\chrome.exe`)
- ✅ x86 경로 확인 (`C:\Program Files (x86)\Google\Chrome\Application\chrome.exe`)
- ❌ 없으면 설치 안내

### 3. 가상환경 생성
- ✅ `venv` 폴더 자동 생성
- ✅ 기존 venv가 있으면 재사용

### 4. Python 패키지 설치
- ✅ `requirements.txt` 기반 자동 설치
- ✅ 다음 패키지들 설치:
  - streamlit (대시보드)
  - pandas (데이터 처리)
  - selenium (브라우저 자동화)
  - webdriver-manager (ChromeDriver 자동 관리)
  - firebase-admin (Firebase 연동)
  - streamlit-autorefresh (대시보드 자동 새로고침)

### 5. ChromeDriver 자동 관리
- ✅ Selenium이 자동으로 ChromeDriver 다운로드 및 관리
- ✅ Chrome 버전에 맞는 ChromeDriver 자동 선택
- ✅ 별도 설치 불필요

### 6. Firebase 인증 파일 확인
- ✅ `iparking-bot/firebase-credentials.json` 존재 여부 확인
- ⚠️ 없어도 프로그램 실행 가능 (Firebase 기능만 사용 불가)

## ⚠️ 수동 설정이 필요한 항목

### 1. Python 환경 변수 (필요시)
- **확인 방법**: 명령 프롬프트에서 `python --version` 실행
- **문제**: "python을 찾을 수 없습니다" 오류
- **해결**: Python 설치 시 "Add Python to PATH" 옵션 체크
- **수동 설정**:
  1. 시스템 환경 변수 편집
  2. PATH에 Python 설치 경로 추가 (예: `C:\Python311\`)

### 2. Chrome 브라우저 설치
- **다운로드**: https://www.google.com/chrome/
- **설치**: 기본 설정으로 설치하면 됨
- **확인**: Chrome이 정상적으로 실행되는지 확인

### 3. Firebase 인증 파일
- **위치**: `iparking-bot/firebase-credentials.json`
- **설정 방법**:
  1. Firebase 콘솔 접속
  2. 프로젝트 설정 → 서비스 계정
  3. 새 비공개 키 생성
  4. 다운로드한 JSON 파일을 `iparking-bot/firebase-credentials.json`로 저장
- **주의**: 이 파일 없이도 프로그램은 실행되지만 Firebase 기능은 사용 불가

### 4. 인터넷 연결
- **필수**: 패키지 설치 시 인터넷 연결 필요
- **필수**: 프로그램 실행 중에도 인터넷 연결 필요 (iParking 사이트 접속)

### 5. 방화벽 설정 (필요시)
- **문제**: 패키지 설치 실패 또는 프로그램 실행 실패
- **해결**: 방화벽에서 Python과 Chrome 허용

## 🔍 환경 확인 명령어

### Python 확인
```bash
python --version
# Python 3.11.x 이상이어야 함

where python
# Python 경로 확인
```

### Chrome 확인
```bash
# PowerShell에서
Test-Path "C:\Program Files\Google\Chrome\Application\chrome.exe"
# True가 나와야 함
```

### 패키지 확인
```bash
venv\Scripts\activate
pip list
# 다음 패키지들이 설치되어 있어야 함:
# - selenium
# - streamlit
# - pandas
# - firebase-admin
# - webdriver-manager
```

### 포트 확인 (Chrome 디버깅 포트)
```bash
# PowerShell에서
Test-NetConnection -ComputerName localhost -Port 9222
# 포트가 열려있으면 프로그램이 Chrome을 제어할 수 있음
```

## 🚨 문제 해결

### Python을 찾을 수 없음
1. Python 설치 확인: https://www.python.org/downloads/
2. 설치 시 "Add Python to PATH" 체크
3. 환경 변수 PATH에 Python 경로 추가
4. 명령 프롬프트 재시작

### Chrome을 찾을 수 없음
1. Chrome 브라우저 설치: https://www.google.com/chrome/
2. 설치 후 프로그램 재실행
3. Chrome이 다른 경로에 설치된 경우, `bot_Simple_logic.py`의 Chrome 경로 수정

### 패키지 설치 실패
1. 인터넷 연결 확인
2. 방화벽 설정 확인
3. 수동 설치 시도:
   ```bash
   venv\Scripts\activate
   pip install selenium streamlit pandas firebase-admin webdriver-manager streamlit-autorefresh
   ```

### ChromeDriver 오류
- Selenium 4.15.0 이상에서는 자동 관리됨
- 문제 발생 시:
  1. Chrome 브라우저 최신 버전으로 업데이트
  2. Selenium 업데이트: `pip install --upgrade selenium`

### Firebase 연결 실패
1. `firebase-credentials.json` 파일 존재 확인
2. 파일 내용이 올바른지 확인
3. Firebase 프로젝트 설정 확인
4. 없어도 프로그램은 실행되지만 Firebase 기능만 사용 불가

## 📝 체크리스트

설치 전 확인:
- [ ] Python 3.8 이상 설치됨
- [ ] Chrome 브라우저 설치됨
- [ ] 인터넷 연결됨
- [ ] `firebase-credentials.json` 파일 준비됨 (선택사항)

설치 후 확인:
- [ ] `설치_및_실행.bat` 실행 성공
- [ ] 가상환경 생성됨 (`venv` 폴더 존재)
- [ ] 패키지 설치 완료
- [ ] 프로그램 실행 테스트 성공

## 💡 팁

1. **첫 실행 시**: ChromeDriver가 자동으로 다운로드되므로 시간이 걸릴 수 있습니다
2. **Chrome 업데이트 시**: ChromeDriver도 자동으로 업데이트됩니다
3. **여러 컴퓨터 사용 시**: 각 컴퓨터에서 `설치_및_실행.bat`를 한 번씩 실행하면 됩니다
4. **업데이트 시**: 새로운 패키지가 필요하면 `pip install -r requirements.txt --upgrade` 실행
