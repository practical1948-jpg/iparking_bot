# 🚗 iParking 자동화 시스템 - 실행 방법 정리

## 📋 실행 방법 (3가지)

### 🌟 방법 1: 원클릭 통합 실행 (추천!)

**가장 간단한 방법 - 모든 것이 자동!**

```
📁 start.bat 더블클릭
또는
📁 통합_실행.bat 더블클릭
```

**무슨 일이 일어나나요?**
1. 대시보드가 별도 창에서 자동 시작 ✅
2. 브라우저가 자동으로 열림 (http://localhost:8501) ✅
3. 메인 창에서 주차 프로그램 실행 ✅
4. 차량 정보 입력하면 자동 등록 시작! ✅

---

### 🔧 방법 2: 개별 실행

**대시보드와 봇을 따로 실행하고 싶을 때**

#### 1단계: 대시보드 실행
```
📁 대시보드_실행.bat 더블클릭
```

#### 2단계: 봇 실행
```
📁 봇_실행.bat 더블클릭
```

**언제 사용하나요?**
- 대시보드는 이미 실행 중이고, 봇만 다시 시작하고 싶을 때
- 디버깅할 때
- 대시보드만 보고 싶을 때

---

### 💻 방법 3: 수동 실행 (고급)

**터미널 명령어로 직접 실행**

```bash
# 1. 가상환경 활성화
venv\Scripts\activate

# 2. 폴더 이동
cd iparking-bot

# 3. 대시보드 실행 (선택)
streamlit run dashboard.py

# 4. 봇 실행 (다른 터미널에서)
python "Last update_parkingbot.py"
```

**언제 사용하나요?**
- 개발자 모드
- 배치 파일이 작동하지 않을 때
- 세밀한 제어가 필요할 때

## 🎯 추천 사용 흐름

### 📅 매일 사용 시

```
1. start.bat 더블클릭 (아침에 1번만)
   ↓
2. 주차 프로그램에서 차량 등록
   ↓
3. 대시보드에서 실시간 확인
   ↓
4. 주차 프로그램 종료해도 대시보드는 계속 실행
   ↓
5. 추가 차량 등록 필요? → 봇_실행.bat 다시 실행
```

### 🔄 봇만 재실행 필요할 때

```
1. 대시보드는 이미 실행 중
   ↓
2. 봇_실행.bat 더블클릭
   ↓
3. 새로운 차량 등록
```

## ❓ 문제 해결

### Q1: start.bat 실행했는데 에러가 나요
**A:** 
1. 가상환경이 설치되었는지 확인
   → `빠른_설치.bat` 먼저 실행
2. 파일 위치 확인
   → `iparking-bot` 폴더 안에 `Last update_parkingbot.py`가 있는지 확인

### Q2: 대시보드는 열렸는데 봇이 실행 안 돼요
**A:**
1. Chrome이 디버그 모드로 열려있는지 확인
2. 구글 시트 인증 파일이 있는지 확인
3. Firebase 인증 파일이 있는지 확인

### Q3: 대시보드를 닫고 싶어요
**A:**
- "iParking Dashboard" 창을 닫으면 됩니다
- 또는 터미널에서 Ctrl+C

### Q4: 봇만 다시 실행하고 싶어요
**A:**
- 메인 창만 닫으세요 (대시보드는 계속 실행)
- `봇_실행.bat` 다시 더블클릭

### Q5: 모든 걸 종료하고 싶어요
**A:**
1. 메인 창 닫기 (또는 Ctrl+C)
2. "iParking Dashboard" 창 닫기 (또는 Ctrl+C)
3. 브라우저 탭 닫기 (선택)
