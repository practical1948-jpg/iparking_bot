✨ 처음 사용하는 경우
────────────────────────────────────────────────────────────
1. "빠른_설치.bat" 실행 (한 번만!)
2. "🚀 여기를 실행하세요 START.bat" 실행


📌 일반 사용법
────────────────────────────────────────────────────────────

🚀 여기를 실행하세요 START.bat  ← 이것만 더블클릭!

↓

옵션 선택 화면:
   1. 주차 명단 (CSV 파일 자동 처리)
   2. 수동 입력 (이름 + 차량번호 직접 입력)

↓

Chrome 자동 실행 → 처리 시작!


═══════════════════════════════════════════════════════════
 📁 주요 파일 설명
═══════════════════════════════════════════════════════════

✅ 🚀 여기를 실행하세요 START.bat   ← 메인 실행 파일 (매일 사용)
📦 빠른_설치.bat                     ← 초기 설치 (한 번만 실행)
📋 📋 사용방법_여기를_읽으세요.txt   ← 이 파일

⚠️ 다음 폴더는 건드리지 마세요:
   - venv/              ← 가상환경 (시스템)
   - iparking-bot/      ← 소스코드 (개발자용)
   - 주차_DB_파일/      ← 데이터베이스


═══════════════════════════════════════════════════════════
 🔧 문제 해결
═══════════════════════════════════════════════════════════

❌ "가상환경을 찾을 수 없습니다" 에러
   → 빠른_설치.bat 실행

❌ Chrome 브라우저가 안 열려요
   → 기존 Chrome 창 모두 닫고 다시 시도

❌ 옵션 선택 화면이 안 나와요
   → "🚀 여기를 실행하세요 START.bat" 사용하는지 확인!

❌ 프로그램이 멈췄어요
   → 모든 창 닫기 → 다시 실행

 💡 팁
═══════════════════════════════════════════════════════════

• 대시보드: 별도 창에서 계속 실행
  주소: http://localhost:8501

• 주차 프로그램만 종료: 메인 CMD 창 닫기
• 대시보드만 종료: "iParking Dashboard" 창 닫기
• 전체 종료: 두 창 모두 닫기
