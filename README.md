# 🚗 iParking-Bot - 주차권 자동 등록 시스템

iParking 사이트에서 주차권을 자동으로 등록하는 봇 프로그램입니다.

## ✨ 주요 기능

- 📊 **CSV 파일 기반 대량 등록**: 주차 명단 CSV 파일을 읽어 자동 등록
- ✍️ **수동 입력 모드**: 차량번호를 직접 입력하여 등록
- 🔄 **자동 반복 실행**: 5분마다 자동으로 실행 (CSV 모드)
- 📈 **실시간 대시보드**: 웹 브라우저에서 등록 현황 확인
- 🔥 **Firebase 연동**: 데이터를 Firebase에 저장하여 여러 컴퓨터에서 공유
- 🔄 **세션 자동 복구**: 세션 만료 시 자동으로 재로그인

## 🚀 빠른 시작

### 처음 설치하시나요?

**📘 [설치_가이드.md](설치_가이드.md)를 참고하세요!**
- 다른 컴퓨터로 폴더 이동부터 설치, 실행까지 전체 과정 설명
- 문제 해결 방법 포함

### 간단 실행 (이미 설치한 경우)

```bash
# 설치_및_실행.bat 파일을 더블클릭
# → 메뉴에서 1(봇) 또는 2(대시보드) 선택
```

### 수동 실행

```bash
# 가상환경 활성화
venv\Scripts\activate

# 봇 실행
cd iparking-bot
python bot_Simple_logic.py

# 대시보드 실행
cd iparking-bot
streamlit run dashboard.py
```

## 📦 배포 방법

### 다른 컴퓨터로 배포하기

1. **배포 패키지 생성**
   ```bash
   # 배포_패키지_생성.bat 실행
   ```
   - `iparking-bot_배포패키지.zip` 파일이 생성됩니다

2. **다른 컴퓨터에 배포**
   - 생성된 ZIP 파일을 다른 컴퓨터로 전송
   - 압축 해제
   - `설치_및_실행.bat` 실행

3. **즉시 사용 가능**
   - 모든 경로가 상대 경로로 설정되어 있어 어디에 설치해도 작동합니다
   - 추가 설정 없이 바로 실행 가능

## 📁 프로젝트 구조

```
iparking-bot/

주차_DB_파일/                     # CSV 파일 저장 폴더
  └── *.csv

설치_및_실행.bat                  # 자동 설치 스크립트
배포_패키지_생성.bat              # 배포 패키지 생성 스크립트
배포_가이드.md                    # 상세 배포 가이드
```

## ⚙️ 설정

### Firebase 설정

1. Firebase 콘솔에서 서비스 계정 키 다운로드
2. `iparking-bot/firebase-credentials.json`에 저장
3. (없어도 프로그램은 실행되지만 Firebase 기능은 사용 불가)

### CSV 파일 준비

1. 주차 명단 CSV 파일을 `주차_DB_파일` 폴더에 저장
2. 프로그램 실행 시 자동으로 최신 파일을 선택

## 🔧 주요 기능 설명

### CSV 모드
- 주차 명단 CSV 파일을 읽어 자동 등록
- 5분마다 자동으로 반복 실행
- 회차 자동 계산 및 기록

### 수동 입력 모드
- 차량번호를 직접 입력하여 등록
- 여러 차량을 연속으로 입력 가능
- 입력 완료 후 자동 처리

### 대시보드
- 실시간 등록 현황 확인
- 날짜별 필터링
- 상태별 통계
- CSV 다운로드

## 📝 사용법

### 봇 실행

1. 프로그램 실행
2. 데이터 입력 방식 선택:
   - `1`: CSV 파일 모드
   - `2`: 수동 입력 모드
3. 자동 처리 시작

### 대시보드 실행

```bash
cd iparking-bot
streamlit run dashboard.py
```

- 브라우저가 자동으로 열립니다
- 기본 주소: http://localhost:8501

## 🔄 업데이트

프로그램을 업데이트할 때:

1. 새로운 `.py` 파일로 교체
2. 필요시 패키지 업데이트:
   ```bash
   pip install -r requirements.txt --upgrade
   ```
3. 기존 데이터는 자동으로 유지됩니다

## ⚠️ 주의사항

- Chrome 브라우저가 설치되어 있어야 합니다
- 인터넷 연결이 필요합니다
- Firebase 인증 파일이 필요합니다 (Firebase 기능 사용 시)
- 세션 만료 시 자동으로 재로그인됩니다

## 📞 문제 해결

### Python을 찾을 수 없음
- Python 3.8 이상 설치 필요
- 환경 변수 PATH 확인

### 패키지 설치 실패
- 인터넷 연결 확인
- 방화벽 설정 확인

### Chrome 관련 오류
- Chrome 브라우저 설치 확인
- ChromeDriver 자동 다운로드 확인
