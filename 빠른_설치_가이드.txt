  🚗 iParking-Bot 빠른 설치 가이드
═══════════════════════════════════════════════════════════

📌 다른 컴퓨터로 이동 시 설치 방법 (5분 완성!)

───────────────────────────────────────────────────────────
1️⃣ 사전 준비 (필수!)
───────────────────────────────────────────────────────────

✅ Python 3.8 이상 설치
   └─ https://www.python.org/downloads/
   └─ 설치 시 "Add Python to PATH" 체크 필수!

✅ Google Chrome 브라우저 설치
   └─ https://www.google.com/chrome/

✅ 인터넷 연결 확인

───────────────────────────────────────────────────────────
2️⃣ 폴더 이동
───────────────────────────────────────────────────────────

방법 A: 폴더 전체 복사
   └─ iparking-bot 폴더를 USB/클라우드로 이동

방법 B: 압축 파일 (권장)
   1) 원본 PC에서 "배포_패키지_생성.bat" 실행
   2) 생성된 ZIP 파일을 새 PC로 전송
   3) 원하는 위치에 압축 해제
      (예: C:\iparking-bot 또는 D:\작업\iparking-bot)

───────────────────────────────────────────────────────────
3️⃣ 자동 설치 (30초!)
───────────────────────────────────────────────────────────

📂 "설치_및_실행.bat" 파일을 더블클릭!

→ 자동으로 모든 것이 설치됩니다:
   ✓ Python 확인
   ✓ Chrome 확인
   ✓ 가상환경 생성
   ✓ 패키지 설치 (selenium, streamlit, pandas 등)
   ✓ Firebase 설정 확인

───────────────────────────────────────────────────────────
4️⃣ 실행
───────────────────────────────────────────────────────────

설치 완료 후 메뉴가 나타납니다:

   ═══════════════════════════════════
      iParking Bot 실행 메뉴
   ═══════════════════════════════════
   1. 주차권 등록 봇 실행
   2. 대시보드 실행
   3. 종료

   선택: 

→ 원하는 번호를 입력하고 Enter!

───────────────────────────────────────────────────────────
5️⃣ 완료! 🎉
───────────────────────────────────────────────────────────

이제 사용 가능합니다!

📊 대시보드: http://localhost:8501 (자동으로 열림)
🤖 봇 프로그램: 명령창에서 작동

───────────────────────────────────────────────────────────
❓ 문제가 생겼나요?
───────────────────────────────────────────────────────────

🔴 "python을 찾을 수 없습니다"
   → Python 설치 후 "Add Python to PATH" 체크
   → 명령 프롬프트 재시작

🔴 "Chrome을 찾을 수 없습니다"
   → Chrome 브라우저 설치
   → https://www.google.com/chrome/

🔴 패키지 설치 실패
   → 인터넷 연결 확인
   → 방화벽에서 Python 허용

🔴 가상환경 활성화 오류 (PowerShell)
   → 관리자 권한으로 PowerShell 실행
   → Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
   → 또는 명령 프롬프트(cmd) 사용
