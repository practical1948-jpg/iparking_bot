========================================
주차 명단 자동화 프로그램 사용 방법
========================================

[방법 1] 배치 파일 사용 (가장 간단)
-----------------------------------
Windows에서 배치 파일을 더블클릭하거나 명령줄에서 실행:

1. 차량번호 정형화:
   차량번호_정형화.bat "(신규)주차등록(응답) - 차량_DB 시트.csv"

2. 주차 명단 생성:
   주차명단_생성.bat "(신규)주차등록(응답) - 차량_DB 시트.csv"
   주차명단_생성.bat "(신규)주차등록(응답) - 차량_DB 시트.csv" --html-only

※ 더 깔끔한 새 레이아웃(표 없이 “디렉토리 스타일”)은 아래 파일을 사용하세요:
   주차명단_정렬_v3.html


[방법 2] Python 스크립트 직접 실행
-----------------------------------

1. 차량번호 정형화
------------------
차량번호의 공백을 제거하여 정형화합니다.

기본 사용법:
  python 차량번호_정형화.py "CSV파일경로"

예시:
  python 차량번호_정형화.py "(신규)주차등록(응답) - 차량_DB 시트.csv"

옵션:
  - 원본 파일 수정 (기본): 백업 파일 자동 생성
  - 새 파일로 저장: 출력 파일명 지정
  - --verbose: 변경된 차량번호 상세 출력
  - --no-backup: 백업 파일 생성 안 함

예시 (새 파일로 저장):
  python 차량번호_정형화.py "입력.csv" "출력.csv"

예시 (상세 출력):
  python 차량번호_정형화.py "입력.csv" --verbose


2. 주차 명단 HTML 생성
---------------------
CSV 파일을 읽어서 가나다 순으로 정렬하고 HTML 파일을 생성합니다.

기본 사용법 (대화형 모드):
  python 주차명단_자동화.py "CSV파일경로"

예시:
  python 주차명단_자동화.py "(신규)주차등록(응답) - 차량_DB 시트.csv"

자동 모드 (HTML만 생성, 브라우저 자동 열기):
  python 주차명단_자동화.py "CSV파일경로" --html-only

자동 모드 (CSV와 HTML 모두 생성):
  python 주차명단_자동화.py "CSV파일경로" --auto

옵션:
  --html-only    HTML 파일만 자동 생성 (브라우저 자동 열기)
  --auto         CSV와 HTML 모두 자동 생성
  --no-browser   브라우저 자동 열기 안 함


3. 전체 작업 흐름
-----------------
1) 차량번호 정형화
   python 차량번호_정형화.py "(신규)주차등록(응답) - 차량_DB 시트.csv"

2) 주차 명단 HTML 생성
   python 주차명단_자동화.py "(신규)주차등록(응답) - 차량_DB 시트.csv"

3) HTML 파일을 브라우저에서 열어 확인 및 프린트
   - 표 스타일: 주차명단_정렬_v2.html
   - 표 없이 깔끔한 스타일(추천): 주차명단_정렬_v3.html


========================================
주의사항
========================================
- 차량번호 정형화는 원본 파일을 수정하므로 백업 파일이 자동 생성됩니다.
- 백업 파일은 .backup.csv 확장자로 저장됩니다.
- 파일 경로에 공백이 있으면 따옴표로 감싸주세요.


========================================
인쇄 시 헤더/풋터 제거 방법
========================================
HTML 파일을 인쇄할 때 상단/하단에 파일 경로가 표시되는 경우:

[Chrome/Edge 브라우저]
1. Ctrl + P (인쇄 미리보기 열기)
2. 우측 설정에서 "추가 설정" 클릭
3. "머리글 및 바닥글" 옵션을 "끄기"로 설정
4. 인쇄 또는 PDF로 저장

[Firefox 브라우저]
1. Ctrl + P (인쇄 미리보기 열기)
2. "페이지 설정" 클릭
3. "여백 및 머리글/바닥글" 탭에서
4. 머리글과 바닥글을 모두 "--공백--"으로 설정

※ 이 설정은 한 번만 하면 다음에도 유지됩니다.
